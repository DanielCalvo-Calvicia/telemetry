# enums

The enums of the contract: severity (`severity.md`, T-02.2), the execution states and their valid transitions (`execution_transitions.yaml`, T-07.1) and, in `device/` and `ai/`, the allowed values of the device and AI fields (REQ-DEV-005, REQ-AI-005). Adding a value is a MINOR change of the contract (REQ-VER-003). Empty for now.
