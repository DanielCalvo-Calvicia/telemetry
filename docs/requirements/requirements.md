# Requirements

Status as of 2026-11-03. **Done** means implemented and verified in the repository (tests pass); **Planned** means decided and not built. Where a row names a record, it is the ADR that explains the decision.

The rows FR-1 to FR-20 and NFR-1 to NFR-7 were written for the first library (the module with `pkg/logging`, released as `v0.1.0` and `v0.2.0`). That library was **removed from the tree in T-04.7 (2026-11-03)**; its tags stay on the Go proxy and it is not maintained. Each row now says what the library of the new standard does about it, with the task that built it; the rows of the new standard are in the last table, with the REQ ids of [PR-001](../proposals/PR-001-telemetry-standard-go-python.md).

## Functional: logging

| ID | Requirement | Status | Record |
|---|---|---|---|

| FR-2 | A log entry carries its category, function, message and free fields; the severity comes from the method and the time from the clock of the core. | Done by the new library (T-04.1): `LogEntry{Category, Function, Message, Fields}` becomes the event `log.entry.recorded`; the producer, depth and process id fields of the old entry do not exist any more (the application is the resource of the configuration, the ids come from the call context) | ADR-013 |
| FR-3 | The minimum level follows the environment (`APP_ENV`, no level variable). | **Replaced** (T-04.2): each destination has its own `minimum_severity` setting (`INFO` by default) that the project passes in; the library does not read the environment | ADR-007 (old library) |

| FR-14 | A ready-made constructor per destination, and a way to add a destination of the consumer. | Done by the new library (T-04.2 to T-04.6): `NewDestination(settings)` and `DefaultSettings()` in each adapter package; a destination of the consumer implements a sink port and is passed with `WithLogSink` | ADR-009, ADR-013 |
| FR-15 | Metrics (counters, gauges, histograms) behind outbound ports, with one real adapter. | Planned: the new standard has the metrics port and `WithMetricsSink`, and the adapters come in their own task ([PR-001](../proposals/PR-001-telemetry-standard-go-python.md)) | ADR-013 |

## Out of scope

Deployment of any kind; reading environment variables or files; sending entries to AWS directly (CloudWatch is reached through aws_microservice); log rotation and retention (CloudWatch's concern).
