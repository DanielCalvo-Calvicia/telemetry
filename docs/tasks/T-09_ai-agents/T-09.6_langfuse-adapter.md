## Goal

In Go (a module of its own) and in Python (an extra): an AI telemetry destination that sends the `ai.*` events and their traces to Langfuse with the same observable behavior in both languages (REQ-AI-009, REQ-AI-010).

## Design notes

- Python uses the Langfuse SDK and Go the approach recorded by T-09.5 (the HTTP or OTLP API unless the check finds an SDK) (D-09). The adapter implements `AITelemetrySinkPort` and is chosen by the project by importing it and passing it in code (REQ-ARC-013); it does not register itself on import.
- One mapping table, written in `docs/api/api.md`, says what each `ai.*` event becomes in Langfuse (a trace, a generation, a span, an event). Both languages implement the table and a shared fixture proves it.
- Credentials and the URL come from the consumer's configuration (ADR-004, REQ-SEC-007) and never appear in logs or diagnostics. TLS verification is on by default (REQ-SEC-005).
- A failing Langfuse never fails the agent (ADR-005); it is counted in diagnostics. The events are masked before they reach this adapter (ADR-006).
- Go: `go/pkg/ai_telemetry/langfuse/` has its own `go.mod`, pins a minimum version of the core and has its own tag `go/pkg/ai_telemetry/langfuse/vX.Y.Z` (ADR-013). The core never imports it.
- Question to the maintainer: one extra `ai` (REQ-DST-002 names `telemetry[ai]`) for Langfuse, LangChain and LlamaIndex together, or one extra per adapter so a project installs only what it uses (REQ-DST-004)?

## Acceptance criteria

- For the same input events, the Go and the Python adapters send the same observable result to the fake Langfuse (same traces, observations, names, usage and timing fields).
- An unreachable or failing Langfuse is counted and never raises into the caller.
- No key or token appears in a log, in diagnostics or in a committed file.
- Importing the Go core does not pull in the Langfuse module; installing Python without the extra does not install its SDK.
- Two agents sending at once produce separate traces.

Ends with the checks of the README section 3 green in every language the task names.
