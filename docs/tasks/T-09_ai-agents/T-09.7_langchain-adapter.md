## Goal

In Python (an extra): instrument LangChain so its runs, model calls and tool calls produce the events of T-09.2, and mark the adapter "not applicable" in Go in the capabilities registry (REQ-AI-009, REQ-AI-011).

## Design notes

- Q05-2 chose to have LangChain and LlamaIndex even if no project uses them yet ("more and unused than left"), and Q07-14 made them Python only.
- The adapter is a callback handler of the framework that calls the generic callbacks of T-09.2; it adds no event type and no schema (REQ-AI-003). It lives at `outbound/ai_runtime/langchain/` (REQ-AI-009), in Python at `python/src/telemetry/ai_runtime/langchain/`.
- The framework is a third-party dependency and is installed separately (REQ-DST-004) through an extra. The core and the other extras never import it.
- In Go there is no directory: `contracts/capabilities/registry.yaml` marks the adapter "not applicable" in Go and that does not block REQ-CNF-007 (REQ-AI-011). The parity check of T-12.3 accepts this single exception (REQ-ARC-011).
- Content follows the privacy rules of T-09.3: metadata only unless switched on.
- Tests never call a real model or the network: they use the fake model and fake tools that the framework offers for tests.
- Questions to the maintainer:
  1. Which LangChain versions must be supported (a range)? Nothing in the answers names one.
  2. Does the existing agent use LangChain? This decides whether T-09.9 exercises this adapter.

## Acceptance criteria

- A chain with a fake model and a fake tool produces `ai.model.*`, `ai.tool.*` events that validate against the schemas, with `parent_execution_id` that follows the nesting of the chain.
- An exception inside the chain is reported as `ai.model.failed` or a failed tool and is re-raised unchanged.
- Installing the package without the extra does not install LangChain; importing the core never imports it.
- The registry shows Go as "not applicable" and the registry check of T-02.7 passes.

Ends with the checks of the README section 3 green in every language the task names.
