## Goal

In Go and in Python: by default the AI events carry only metadata; full prompts, tool results and images need an explicit switch, a size limit and redaction (REQ-AI-006), telemetry never grants permissions (REQ-AI-008) and usage is reported as token counts only (REQ-AI-012).

## Design notes

- Metadata only is the default (Q05-4, option a). The maintainer noted that it "may change depending on the requirements", so the switch exists per kind of content (prompt, tool result, image) and is off by default.
- When a switch is on, the content passes the redaction of T-03.4 (by field name and by pattern) before any destination, and is cut at a configurable size limit; a cut is marked and counted in diagnostics. Nothing is sent unmasked (ADR-006).
- Every switch and limit is a `Config` field with a tag (the library never reads the environment, ADR-004); the consumer loads it.
- The callbacks of T-09.2 have no return value and no hook that lets telemetry decide whether a tool runs or a device moves (REQ-AI-008). A test calls them with a failing sink and with hostile content and shows that the caller's flow is unchanged.
- Usage is `input_tokens`, `output_tokens`, `total_tokens` and nothing else; the library never computes a cost (Q05-5, REQ-AI-012).
- Questions to the maintainer:
  1. Are there kinds of content that must never be recorded even with the switch on (Q05-4 option b was not chosen; for example personal data of customers)?
  2. Are images recorded as bytes, or only as a reference (size, type, hash)?
  3. What are the default size limits for a prompt and a tool result?
  4. The field that carries the content depends on the answer of T-09.1 (optional fields in `data`).

## Acceptance criteria

- With the defaults, no event contains a prompt, a tool result or an image.
- With a switch on, content appears, is masked (a planted token never reaches the sink) and is cut at the limit with a marker.
- Usage never contains a cost.
- No callback influences the caller's decision to run a tool.
- An invalid limit is rejected at start with an error that names the field.

Ends with the checks of the README section 3 green in every language the task names.
