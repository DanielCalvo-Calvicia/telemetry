## Goal

Keep the route to the `add_log` endpoint of aws_microservice: the adapter translates a `log.*` event to the `add_log` contract, as ADR-008 does today, and lives in a module of its own (Q07-10, ADR-013).

## Design notes

- The translation reverses the old mapping: the application comes from `resource.service_name`; category, function and message come from `data`; extra fields from `attributes`. The old request builder (`build_add_log_request`) is the starting point, adapted to the event.
- Only `log.*` events are translated. Other event types are ignored by this adapter and counted, because the `add_log` contract has no place for them (section 7.2 marks only logs).
- Go: its own module `go/pkg/logging/aws_http/` with its own `go.mod`, a minimum core version pinned, its own tag `go/pkg/logging/aws_http/vX.Y.Z` and an entry in `go.work` (REQ-DST-001). The core is released first. The module must build alone: the rule that `internal/` packages of the core can be imported from a nested module is to be verified here (known risk of PR-001).
- Python: an extra of the package, the proposal being `telemetry[aws_http]`. The extra name is not decided (PR-001 lists `telemetry[sqlite]`, `[otel]`, `[prometheus]`, `[ai]` only): question to the maintainer.
- Public packages: `go/pkg/logging/aws_http` and `telemetry.logging.aws_http`. The project passes the adapter to the core in code (REQ-ARC-013); the adapter does not register itself.
- Host, port, path, log group and log stream come from the consumer's configuration; the repository holds placeholders only (`my-log-group`, `localhost`).

## Acceptance criteria

- A `log.entry.recorded` event becomes the same `add_log` request the old adapter built for the equivalent entry.
- The module builds and tests with only its own dependencies and the core, and importing the core does not pull its dependencies in.
- An event that is not a `log.*` event is skipped and counted.
- Any empty required setting is a configuration error that names the field.

Ends with the checks of the README section 3 green in every language the task names.

Golden test of the request for a fixture event; a test with a local fake receiver; `go build ./...` and `go test ./...` run from inside the module directory with `go.work` disabled.
