## Goal

Append events to a local file as JSON Lines, with configurable rotation and a disk quota (section 7.2).

## Design notes

- One canonical JSON event per line. The directory and file name come from the configuration the consumer passes in; the library never picks a path (same rule as the spool, REQ-SPL-001).
- Rotation by size, and a quota on the total space the files may use. The names of the settings come from the configuration of T-03.6. The numbers (maximum file size, number of files, quota) have no default in PR-001: question to the maintainer, who may accept proposed values.
- Question to the maintainer: when the quota is reached, is the oldest rotated file deleted first? PR-001 says "rotation and quota" and gives no full-disk policy for this adapter.
- A write failure (disk full, permission) is classified and counted; it never fails the log call (ADR-005) and never stops the other destinations (REQ-DLV-005).
- The file is for operators and tools such as a log shipper; it is not the SQLite destination (T-06.6) and has no reader contract.
- Same folder question as T-04.2.

## Acceptance criteria

- Each event is one line; Go and Python write the same bytes for the same event.
- When the size limit is reached the file rotates; when the quota is reached the documented policy applies and a counter records it.
- A path the process cannot write gives a classified error at start, with the field and the reason (REQ-CFG-002).
- A failed write is dropped and counted without failing the caller.

Ends with the checks of the README section 3 green in every language the task names.

- **Built.** The file destination (both ports), the settings and their validation, the two pure plans (rotation, quota), the counters, the dependencies file and the public packages. See section 2.21 of the architecture document.
- **Verification.** The 9 scenarios, the rotation plan, the quota plan and the settings cases pass in Go and Python with no edit by the agents (one expected counter changed on purpose made both fail, restored both pass); the public names are checked in both. A **differential test of 400 random scenarios** (sizes, files, quotas, severities, several batches, messages with line breaks, quotes and non-ASCII) gave **0 differences** in the files left in the directory, the counters and the results. Go: `gofmt` and `goimports` clean, vet and build clean, all tests pass (architecture included), coverage **98.1%**; `go.mod` still has no `require` line. Python: `ruff` clean, **601 tests**, coverage **100%** (`external/` omitted by the repository configuration but tested directly). The registry: no requirement moved to covered (`REQ-ARC-014` waits for the HTTP adapter, T-04.5); the logging capability block now says what is built.
- **Open questions, decided with the defaults (the maintainer was not asked).** The adapter lives under `outbound/logging/file/`. When the quota is reached the oldest rotated file is deleted first. The numbers (10 MiB per file, 5 files, 50 MiB) are proposed values, as PR-001 gives none.
- **Choices.** The file is opened for each line and closed at once (no handle, rotation works on Windows, one open per event). The rotation is by size only. A line larger than the file size is written to an empty file. Files are `0600`. The start error has one problem on `directory` with no path. The JSON line encoder is duplicated in the file adapter (5 lines) so that the two adapters stay independent; a test proves the bytes equal the console's. Python adds `O_BINARY` on Windows so that a line feed is not turned into a carriage return and a line feed.
- **Known gaps.** No compression and no rotation by time. The cost of an open per event (about 15 ms per line on the Windows machine of the tests, according to the Python agent; T-05 writes by batches). A few error branches (listing the directory failing, an unusual `stat` error) cannot be made to fail portably and are not covered. The Go race detector was not run (no cgo). The agent of the Python half left two Python processes for a few minutes after a hung test run; they ended by themselves.
