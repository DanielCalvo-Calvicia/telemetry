## Goal

Prove, in Go and in Python, that the same transitions and the same events come out of both languages on shared fixtures, before the T-12 runner exists.

## Design notes

- The fixtures live in `integration-tests/fixtures/` so both languages read the same files (REQ-CNF-005). The expected output is the canonical JSON of T-02.5.
- Fixtures: the 64 pairs of states with their expected result; one life cycle per kind of execution (cronjob, worker, agent run) with its expected events; faults of every category; reports; health snapshots.
- Only deterministic values: a fake clock and a fake id generator give the same `occurred_at`, `recorded_at` and `event_id` in both languages.
- Names, hosts and ids in the fixtures are placeholders (public repository).
- The job in CI that runs every fixture in both languages is T-12.1; this task writes the fixtures and the per-language tests that T-12.1 will call.

## Files

- `integration-tests/fixtures/execution/`, `integration-tests/fixtures/fault/`, `integration-tests/fixtures/report/`, `integration-tests/fixtures/health/` (inputs and `*.canonical.json` outputs)
- `go/internal/tests/contract/execution_cross_test.go`, `go/internal/tests/contract/health_cross_test.go` and the fault and report equivalents
- `python/internal/tests/contract/test_execution_cross.py` and the equivalents for health, fault and report

## Documents updated in the same change

`docs/requirements/requirements.md` (the conformance column of the REQ-EXE, REQ-FLT, REQ-RPT and REQ-HLT rows), `contracts/capabilities/registry.yaml` (the test names of these capabilities), `docs/tasks/ORDER.md` and the board of `docs/tasks/README.md`.

## Acceptance criteria

- Both languages accept and reject the same transitions of the fixture.
- For each fixture, Go and Python produce the same bytes of canonical JSON.
- A life cycle of each of the three kinds of execution gives the same event sequence in both languages.
- A deliberately wrong expected file makes both tests fail.

Ends with the checks of the README section 3 green in every language the task names.
