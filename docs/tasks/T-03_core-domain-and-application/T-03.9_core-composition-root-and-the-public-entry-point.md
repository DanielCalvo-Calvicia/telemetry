## Goal

Wire the core and expose the one function a project calls to build it, with the adapters it chooses passed in code.

## Design notes

- REQ-ARC-013 and ADR-013: `New(config, adapters...)` builds the core; the project imports the adapters it needs and passes them. The configuration carries only adapter settings, never an adapter name; adapters never register themselves on import. In Python the same shape: `telemetry.new(config, *adapters)` (naming rule of T-02.1).
- No mutable global state (REQ-ARC-006). A convenience global instance is optional and documented; it is not built here (see the epic).
- The composition root (`go/internal/composition_root/{config,containers,dependencies}`) wires the services of T-03.3 to T-03.8 in the order of T-03.3 (build, validate, mask, limit, hand over). Only this layer imports concrete adapters (REQ-ARC-003); one dependencies file per adapter (CLAUDE.md).
- The system clock and the UUIDv7 generator are infrastructure adapters of two ports of T-03.2 and no other task writes them: they are written here, ported from `internal/logging/infrastructure/outbound/systemclock` and `uuidgen`. Question to the maintainer: does the Go core keep `github.com/google/uuid` (its only third-party dependency today, which has a v7 generator) or write UUIDv7 itself (REQ-ARC-005)? Default: keep it.
- `Shutdown` exists as a stub that returns an empty result until T-05.4 gives it the real `flush` and `shutdown` (REQ-DLV-010). A `durable` destination without a spool port is refused at start (see T-03.6).
- Decided (T-01.1, 2026-10-28): the public package that holds `New`, `Shutdown` and the shared types is `go/pkg/telemetry`; every adapter stays in its own `go/pkg/<functionality>/<adapter>` package.
- Layers stay: domain imports nothing from the others; application defines ports; `external/`, `error/` and `helpers/` folders per adapter.

## Files

- `go/internal/composition_root/config/`, `containers/`, `dependencies/` (one dependencies file per adapter)
- `go/internal/infrastructure/outbound/shared/system_clock/` and `.../uuid_generator/` (with `external/`, `error/`, `helpers/` as needed)
- `go/pkg/telemetry/telemetry.go` (the public entry point and aliases)
- `python/src/telemetry/internal/composition_root/...`, `python/src/telemetry/internal/infrastructure/outbound/shared/...` and `python/src/telemetry/__init__.py` (the public `new` function)
- `go/internal/tests/composition_root/`, `go/internal/tests/e2e/` (build the core with fakes, emit an event) and the Python twins; tests of the public package beside it

## Acceptance criteria

- With the fakes of T-03.2, `New(config, fake_sink)` returns a core that turns one input into one masked, limited, valid event delivered to the fake sink; the same in Python.
- Two cores in one process do not share state.
- An invalid configuration makes `New` return a classified error naming the field; `Shutdown` returns without error.
- A test greps the sources: no global mutable variable, no `os.Getenv`, no adapter self-registration.
- The architecture tests of T-01.4 pass; an event built in Go and in Python has the same fields.
- Ends with the checks of the README section 3 green in every language the task names.
