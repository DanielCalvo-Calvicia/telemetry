## Goal

In Python: the real hardware project, a Raspberry Pi with several sensors and actuators (Q04-1), reports its readings and actuator changes through the library, and the maintainer checks one run on the real hardware. **Needs the maintainer and the hardware.**

## Design notes

- The Pi runs Python 3.11.4 and the minimum of the library is 3.10 (Q07-6). The project is installed from the Git repository with the `pip` line of the README, never from an index (REQ-DST-002).
- The project keeps its own drivers and objects (D-05, Q04-3); it only calls the helpers of T-08.2 and, for commands, those of T-08.4. It chooses its destinations by importing them and passing them in code (REQ-ARC-013).
- A Pi has no battery clock (Q07-13): the events carry `clock_source` and `clock_synced` when the library knows them, and both times are UTC (Q09-1).
- Offline: the `durable` mode of T-06.5 keeps the events in the spool until the network returns, within the quota of 256 MiB (Q04-5, Q07-11).
- The changes made inside the pilot project are made in the repository of that project; this repository gets a smoke test with fake hardware objects that repeats the calls of the pilot, and the record of what the real run showed.
- Questions to the maintainer:
  1. Which sensors and actuators take part in the run, and at which rate (Q04-4 gives 50 ms as the fastest)?
  2. Which destination is used during the pilot, since no receiver exists yet (Q07-9): the SQLite destination, a file, or the fake receiver of T-04.8?
  3. When will the hardware be available for the run?

## Acceptance criteria

- The smoke test passes with fake hardware: readings, an actuator change and a command with its three events reach the fake receiver.
- On the real hardware, the maintainer confirms that readings and actuator changes of the real project arrive in the chosen destination in the shape of Annex B.
- A run with the network off keeps the events and sends them after reconnection, as T-06.5 promises.
- The project stays unaffected when the destination fails (ADR-005).
