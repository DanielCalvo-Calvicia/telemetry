## Goal

Write the JSON Schema of the event envelope and the severity enum, the base every event of every capability uses.

## Design notes

- Fields of REQ-CTR-001: `schema_version`, `event_id`, `event_type`, `occurred_at`, `recorded_at`, `severity`, `resource`, `actor`, `context`, `data`, `attributes`. Required: all but `actor`, `context` and `attributes`. `data` is required and may be empty.
- `resource` (section 5.2): `service_name` and `instance_id` required; `environment`, `service_version`, `host` and `time_zone` optional. `time_zone` is an IANA name, for display only and never used to compute a time (ADR-012, Q09-1). `actor`: `kind` and `id` required, `type` and `version` optional; `kind` comes from `contracts/enums/`. `context`: `trace_id`, `span_id`, `execution_id`, `correlation_id`.
- Times: `occurred_at` and `recorded_at` are UTC with the fixed format `YYYY-MM-DDTHH:MM:SS.ffffffZ` (REQ-CNF-003, REQ-CTR-008). `recorded_at` is set only by the library; the schema documents that, the code enforces it in T-03.3.
- `event_id` is a UUIDv7 (REQ-CTR-009, Q02-2). `schema_version` is `MAJOR.MINOR` and starts at `0.1` (Q02-6).
- Severity values: `TRACE`, `DEBUG`, `INFO`, `WARN`, `ERROR`, `CRITICAL`; `contracts/enums/severity.md` says what each means and how it maps to `log/slog`, Python `logging` and OpenTelemetry (section 5.3).
- Limits of REQ-CTR-010 (32 attribute keys, key 64, value 256, scalars and lists of scalars only) are written in the schema of `attributes`; the size limit of the whole event (64 KiB) is a rule for T-03.5 and is noted, not a schema keyword. Consumers ignore unknown fields of later MINOR versions (REQ-VER-004), so the schema keeps `additionalProperties` open only where the plan allows.
- The generic `data` schema is an open object; each `event_type` narrows it (T-02.3).

## Acceptance criteria

- The schemas are valid JSON Schema documents and validate themselves (the check of T-02.4 loads them).
- A sample envelope with every field validates; one without `occurred_at`, with a lowercase severity, with a time that is not UTC `Z` or with a nested value in `attributes` is rejected.
- `severity.md` covers the six values and the three mappings.
- No field is described twice: each concept has one field (section 5.2).
